## What Are OpenClaw Plugins and How Do They Work?

OpenClaw plugins extend the [OpenClaw](https://openclaw.ai) personal agent — a self-hosted agent connected to WhatsApp, Telegram, and other chat apps. Plugins add capabilities (email, calendar, web browsing, custom APIs) through OpenClaw's extension system.

Install flow (from OpenClaw docs):

1. Run `openclaw onboard` after installing the agent locally
2. Connect model credentials and messaging accounts
3. Enable plugins from the extensions catalog or community repos

Browse ranked OpenClaw plugins at [/openclaw/plugins](/openclaw/plugins). For MCP-specific tooling, use [/openclaw/mcps](/openclaw/mcps).
