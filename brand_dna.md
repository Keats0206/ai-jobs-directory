# Brand DNA — Artificial Jobs (artificialjobs.dev)

## Overview
- **Website:** https://www.artificialjobs.dev
- **One-liner:** Curated directory of AI engineering jobs, AI coding agent comparisons, and agent ecosystem tools (MCP servers, OpenClaw/Hermes plugins).
- **Category:** AI jobs board + developer tools directory
- **Stage:** Growth / indie
- **Funding:** Not disclosed
- **Founded:** Unknown
- **Team:** Unknown

## What It Does
- Lists remote AI, LLM, ML, and GenAI engineering roles with salary data, updated daily
- Compares top 10 AI coding agents (Hermes, Kilo Code, Cline, Claude Code, Cursor, Windsurf, etc.) with head-to-head matchups
- Curates 150+ agent extensions across OpenClaw plugins, MCP servers, and Hermes plugins
- Monetizes via job posting ($99 one-time) and MCP server listing ($199/mo)

## Target Audience
- AI/ML engineers searching for remote roles at LLM labs and AI startups
- Developers evaluating AI coding agents and agent tooling
- Startups hiring AI talent or listing MCP servers

## Key Differentiators
- Niche focus on AI engineering (not general tech jobs)
- Real salary data aggregated from open roles
- Agent comparison hub ranked by public token usage
- Three-ecosystem agent directory (OpenClaw, MCP, Hermes)

## Competitors
- **Wellfound / YC Jobs** — general startup jobs, less AI-specific
- **Levels.fyi** — salary data, no job board or agent comparisons
- **Cursor.com / docs** — single product, not comparative directory
- **Smithery / MCP registries** — MCP only, no jobs or agent comparisons

## Voice & Messaging
- Direct, developer-first, no fluff
- Data-backed (salary ranges, token usage, role counts)
- Practical comparisons with clear verdicts
